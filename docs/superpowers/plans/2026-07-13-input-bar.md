# 底部「输入条」功能实现计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 在底部快捷键栏「发按键」右侧新增「输入条」按钮，点开后在同一行内联展开一个多行输入框，输入后点「发送」把内容（末尾补回车）发到当前 xterm 并执行，发送后自动关闭。

**Architecture:** 纯前端改动，复用既有 `sendInput()`（→ `wsSend({type:'input'})`）。在 `#hotkeys-bar` 内静态新增按钮 + 隐藏的输入条容器；用一个 `display` 状态在「输入条展开」与「快捷键栏可见」之间切换；textarea 用 `scrollHeight` 自动增高。不动 `server.js`、不加 WebSocket 消息。

**Tech Stack:** 原生 HTML/CSS/JS（xterm.js 单页应用，无打包工具、无框架）。

- **无测试框架 / 无 linter / 无 formatter**（AGENTS.md 明确）——本计划用浏览器手动验证代替单元测试。

**Files:**

**Interfaces:**
- Consumes: `sendInput(data)`（L707，`if (activeId) wsSend({type:'input', id:activeId, data})`）、`addFrontendLog(msg, dir)`（L855 已用，存在）、`activeId`（L70）。

- [ ] **Step 1: 在 `pickAndSend` 之后插入输入条逻辑**

在 `public/index.html` 第 857 行（`pickAndSend` 函数结束的 `}`）与第 859 行（`function openHotkeyEditor()`）之间插入：

```js
        // === 底部输入条（内联多行输入框，发送补回车执行）===
        const inputBarBtn = document.getElementById('inputBarBtn');
        const inputBarWrap = document.getElementById('inputBarWrap');
        const inputBarText = document.getElementById('inputBarText');
        const inputBarSend = document.getElementById('inputBarSend');
        const hotkeysListEl = document.getElementById('hotkeysList');

        // 切换：开↔关
        function toggleInputBar() {
            if (inputBarWrap.style.display === 'flex') {
                closeInputBar();
            } else {
                openInputBar();
            }
        }
        function openInputBar() {
            hotkeysListEl.style.display = 'none';   // 展开时隐藏快捷键栏
            inputBarWrap.style.display = 'flex';     // 输入条独占整行
            inputBarText.value = '';
            autoGrow(inputBarText);
            inputBarText.focus();
        }
        function closeInputBar() {
            inputBarWrap.style.display = 'none';
            hotkeysListEl.style.display = 'flex';    // 恢复快捷键栏
            inputBarText.value = '';
            inputBarText.style.height = 'auto';
        }
        // textarea 自动增高：原生 textarea 不随内容变高，需按 scrollHeight 手动撑高
        function autoGrow(ta) {
            ta.style.height = 'auto';
            ta.style.height = ta.scrollHeight + 'px';
        }
        function sendInputBar() {
            const t = inputBarText.value.replace(/\n+$/, '');  // 去掉末尾换行，避免多发空行
            if (!t) { closeInputBar(); return; }               // 空内容：仅关闭不发送
            sendInput(t.replace(/\n/g, '\r') + '\r');          // \n→\r 并补末尾回车执行
            addFrontendLog('输入条发送: ' + t, 'out');
            closeInputBar();                                   // 发送后自动关闭
        }
        inputBarText.addEventListener('input', () => autoGrow(inputBarText));
        inputBarText.addEventListener('keydown', (e) => {
            if (e.key === 'Escape') { e.preventDefault(); closeInputBar(); }
        });
```
